# Contribute

We welcome contributions. If you are interested in contributing to Dashjoin, let us know!
You'll get to know an open-minded and motivated team working together to build the next generation platform.

* [Join our Slack](https://join.slack.com/t/dashjoin/shared_invite/zt-1274qbzq9-mwxBq4WwSTJsITjrvYV4pA) and say hello
* [Follow us](https://twitter.com/dashjoin) on Twitter

## Reporting Issues

If you found a bug, please [submit an issue](https://github.com/dashjoin/platform/issues/new) on GitHub.
Please include the platform version (see the info page), the steps to reproduce the problem,
what you expected to happen, and what happened instead (e.g. error messages from the UI or the server log).

## Enhancement Requests

Ideas for new features or improvements are welcome as well.
[Open an issue](https://github.com/dashjoin/platform/issues/new) and add the
[enhancement label](https://github.com/dashjoin/platform/issues?q=is%3Aissue+label%3Aenhancement).
Describe the use case you have in mind and why the current functionality does not cover it.

## Pull Requests

To contribute code or documentation:

* fork the [repository](https://github.com/dashjoin/platform) and create a branch for your change
* keep the change focused on a single topic and add or update tests where applicable
* if your change affects the behavior of the platform, update the documentation in the dashjoin-docs folder
* [open a pull request](https://github.com/dashjoin/platform/pulls) that describes the change and references the related issue

If you are looking for a place to start, check out the issues labeled
["good first issue"](https://github.com/dashjoin/platform/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
